# Módulo 01 – Fundamentos de Programação

## Visão Geral

Este módulo tem como objetivo introduzir os conceitos fundamentais de programação, lógica e JavaScript.
Ao final do módulo, o aluno terá compreendido:

- Lógica de programação básica
- Tipos de dados e variáveis
- Estruturas de controle e laços
- Funções e escopo
- Prática com exercícios integradores e desafios

## Diretrizes do Módulo

1. Cada aula terá arquivos interativos: `lessonXX.html`, `quizXX.html`, `practiceXX.html`, `challengeXX.html`.
2. O aluno só avança de aula ao atingir a pontuação mínima nas avaliações.
3. As fases seguem a progressão lógica dos conceitos apresentados, garantindo aprendizado sólido.
4. Atualizações de conteúdo e exemplos serão contínuas para manter o módulo sempre atual.

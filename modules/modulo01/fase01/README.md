# Fase 01 – Lógica de Programação (com JavaScript)

**Descrição da Fase:**
Nesta fase, o aluno aprenderá os conceitos fundamentais de lógica de programação e a execução de códigos básicos em JavaScript. O objetivo é construir uma base sólida de raciocínio lógico, manipulação de variáveis e fluxo de execução, preparando para o desenvolvimento de algoritmos mais complexos.

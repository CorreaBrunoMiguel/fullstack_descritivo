# Módulo 01 – Fundamentos de Lógica de Programação e JavaScript

**Descrição do Módulo:**
O Módulo 01 tem como objetivo introduzir o aluno aos conceitos essenciais de lógica de programação, estruturas de controle, manipulação de variáveis e primeiros passos em JavaScript. Este módulo constrói a base necessária para o desenvolvimento de algoritmos e programas mais complexos nas fases seguintes do curso FullStack com GPT Humanizado.

---

## Estrutura do Módulo

O módulo é dividido em **uma fase inicial (Fase 01)**, que aborda o básico da lógica de programação e do JavaScript:

- **Fase 01 – Lógica de Programação (com JavaScript)**
  - Aula 01 – Introdução à Lógica de Programação e Ambiente JavaScript ✅
  - Aula 02 – Variáveis (`let`, `const`) e tipos primitivos ⬜
  - Aula 03 – Conversão de tipos e coerção ⬜
  - Aula 04 – Operadores ⬜
  - Aula 05 – Estruturas condicionais ⬜
  - Aula 06 – Estruturas de repetição ⬜
  - Aula 07 – Funções básicas ⬜
  - Aula 08 – Desafio Integrador ⬜

---

## Objetivos do Módulo

1. Compreender os fundamentos da lógica de programação e algoritmos.
2. Aprender a configurar o ambiente JavaScript (navegador e Node.js).
3. Aplicar conceitos de variáveis, tipos de dados, operadores e estruturas de controle.
4. Resolver problemas progressivamente, desde exercícios simples até desafios integradores.
